Record clicks? No. Capture work.

업무를 수행하는 순간, 그 과정을 실행 가능한 표준업무로 변환합니다.

사용자의 실제 업무 흐름을 클릭 위치, 앱 전환, 첨부, 제출, 판단 지점까지 구조화하고, 나중에는 초보자 화면 위에 그대로 재생하는 해커톤용 MVP입니다.

데모 보기 시나리오 확인
  • 한 번의 업무 수행 → 5~10개 카드형 단계 자동 생성
  • 스크린샷 + 클릭 강조 + AI 요약 + 주의사항 동시 기록
  • 재생 시 실제 버튼 위치를 라이브 오버레이로 안내

    MVP Scope

    해커톤에서 보여줄 기능만 남겼습니다

    입력 UI

    업무 시작, 업무명 입력, 중요/주의/판단 핫키, 기록 종료.

    자동 감지

    활성 프로그램, 창 제목, 앱 전환, 복사/붙여넣기, 저장/제출, 첨부 이벤트.

    결과 화면

    5~10개 카드 단계 생성, 합치기/삭제/이름 수정, 주의사항 자동 표시.

    따라 하기 모드

    실제 버튼 주변을 강조하며 단계별로 재생하는 초보자 안내 모드.

    반복 탐지

    같은 입력 3건 이상, 불필요한 왕복, 앱 간 이동 흐름을 개선 포인트로 제시.

    스토리텔링

    Capture Work라는 정의로 녹화 기술보다 구조화와 재생 경험을 강조.

    Build Plan

    데모 제작부터 GitHub 업로드까지

    01

    스토리 고정

    구매 요청 시나리오를 기준으로 캡처, 편집, 재생의 세 장면을 구성합니다.

    02

    소개 페이지 제작

    핵심 카피, 카드형 업무 흐름, 인터랙티브 데모 플레이어를 구현합니다.

    03

    GitHub Pages 배포

    Actions로 정적 사이트를 자동 배포해 심사위원이 바로 접근할 수 있게 합니다.

    04

    발표 스크립트 연결

    한 번의 업무 수행이 SOP와 라이브 가이드로 바뀌는 장면을 60초 안에 시연합니다.
