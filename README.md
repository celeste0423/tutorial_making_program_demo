# Capture Work Demo

해커톤 발표용 소개 페이지입니다. 핵심 메시지는 `Record clicks`가 아니라 `Capture work`입니다.

## 포함 내용

- 카드 중심의 업무 캡처 콘셉트 소개
- 구매 요청 시나리오 기반 인터랙티브 데모 플레이어
- MVP 범위, 따라 하기 모드, 반복 입력 탐지 설명
- GitHub Pages 배포용 정적 사이트 구성

## 실행

정적 사이트라서 `index.html`을 브라우저로 열어도 확인할 수 있습니다.

간단한 로컬 서버가 필요하면 아무 정적 서버로 현재 폴더를 서빙하면 됩니다.

## GitHub Pages 배포

1. 새 GitHub 저장소를 생성합니다.
2. 이 디렉터리 내용을 푸시합니다.
3. 저장소 Settings > Pages에서 `GitHub Actions`를 선택합니다.
4. 기본 브랜치에 푸시하면 `.github/workflows/deploy.yml`이 자동 배포합니다.

## 발표 포인트

1. 사용자가 실제 업무를 한 번 수행한다.
2. 시스템이 단계별 스크린샷, 클릭 위치, 앱 전환, 경고를 구조화한다.
3. 나중에는 초보자 화면 위에서 실제 버튼을 다시 강조하며 재생한다.
